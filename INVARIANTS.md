# INVARIANTS

Неявные инварианты и допущения, которые код держит, но нигде не объявляет как
проверяемое условие. Составлено **только** по прочитанному коду (см.
`CODE-MAP.md`).

Колонка «Чем защищён» описывает **фактическое** состояние в рабочем дереве:
тип / рантайм-проверка / dev-диагностика / только комментарий / ничего.
Существующие тесты в этой колонке **не учитываются** — их аудит идёт на Этапе 2,
и опираться на них как на описание поведения на Этапе 1 запрещено.

Колонка «При нарушении» различает:
* **ГРОМКО** — исключение, ошибка React, немедленно видимый сбой;
* **МОЛЧА** — неверный результат, деградация, визуальный рассинхрон без ошибок.
