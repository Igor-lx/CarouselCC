# 08-tests — что пиннит каждый тест

Не «что тестируется», а **что закричит, если сломать**. Для рефактора это
главный вопрос: какой файл упадёт и о чём это скажет.

**Заполняется послойно.** Ниже — разобранные слои.

## D. `client/state/tests/**` — 5 файлов / 1086 строк

| Файл | Что закреплено |
| --- | --- |
| `reducer.test.ts` (603) | вся механика команд. Стартовое состояние; MOVE в цикле (вперёд, назад с оборотом, причина автоплея) и в finite (клампы на обеих границах, отсутствие движения на краю); GO_TO — короткий прыжок без телепорта и дальний с ограниченным преflight'ом плюс отложенной целью; **направление GO_TO по шкале точек** — два теста, включая случай, где цикличный обход короче; MOTION_SETTLED — no-op в покое, посадка шага, разрез середины после преflight'а, посадка подхода, переякоривание при смене цели на лету; START_DRAG/END_DRAG — фиксация жеста, коммит в шаг, откат в snap, мгновенная посадка «уже на цели»; повторный клик — ретаргет на две страницы вперёд от **визуальной** позиции, удержание цели во время очереди, разворот в обратную сторону, **бёрст из 50 кликов не уводит колоду больше чем на две страницы**, автоплей под это правило не подпадает, первый клик после посадки снова обычный; мгновенный режим |
| `useCarouselState.test.tsx` (138) | обвязка, которой не видит редьюсер: **идентичность `dispatch` одна на всю жизнь компонента**; редьюсер получает текущий конфиг, а не прошлый; смена раскладки согласуется **до** команды; возвращаемое состояние никогда не отстаёт от пропа на раскладку; смена колоды — жёсткий сброс |
| `reconcile.test.ts` (179) | три исхода согласования: та же ссылка → то же состояние; структурно равная → подмена только ссылки с сохранением фазы; жёсткий сброс по `dataKey` и по `isFinite`; пропорциональный перенос с коллапсом движения в мгновенную досадку. Отдельно — **идемпотентность (контракт ADR-001)** таблицей из двух случаев; что `image` слайда не входит в `dataKey` (поворот экрана не сбрасывает позицию); и выход из «залипшей» фазы `dragging`, когда колода перестала скользить |
| `validateState.test.ts` (117) | три инварианта валидатора, причём фазовые — **таблицей по всем не-`step-jump` фазам**, а не парой примеров; пустая колода валидна вакуумно; независимые нарушения собираются все разом |
| `layoutBuilder.ts` (49) | не тест, а общая фикстура слоя: `makeLayout`, `makeState`, список `NON_JUMP_PHASES`. Комментарий в шапке объясняет, почему она одна на слой: дублировать её по файлам — дублирование внутри одной единицы кода, то есть дефект |

**Чего в слое не закреплено:** ветка `direction === 0` в `MOTION_SETTLED`
(«вырожденная») собственного теста не имеет.

## B. `client/config/**` — собственных тестов нет

Слой не покрыт ни одним тестом напрямую, и это не пробел: проверять в нём нечего,
кроме сборки объекта. Значения косвенно закреплены в двух местах:

- `modules/Diagnostic/checks/constantChecks.ts` и его тесты — сверка
  опубликованных значений с реальными;
- `client/tests/carouselContract.test.tsx` — держит `REPEATED_CLICK_VISUAL_LOOKAHEAD_PAGES`
  вместе с поведением, которое от него зависит.

Что **не** закреплено ничем: `withDefault` пропускает `-1`, `0`, `NaN` и строку
там, где ждут число. По ADR-002 это осознанно, но тестом не зафиксировано —
значит и не заметит, если однажды кто-то решит «добавить валидацию».

| `renderWindow.test.ts` (129) | буферное окно **всегда** содержит сегмент (перебор пяти пар, включая дробные и обратные), буфер по целым экранам с каждой стороны, цикл не клампится, finite клампится в данные, нескользящая колода рендерит саму себя, пустая даёт вырожденное окно. `expandWindow` только расширяет — это и есть «слайд не пропадёт посреди поездки» |
