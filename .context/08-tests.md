# 08-tests — что пиннит каждый тест

Не «что тестируется», а **что закричит, если сломать**. Для рефактора это
главный вопрос: какой файл упадёт и о чём это скажет.

**Заполняется послойно.** Ниже — разобранные слои.

## O. `shared/**/tests/**` — полки, 47 файлов / 5526 строк

Полки тестируются как самостоятельные продукты: ни один файл ниже не знает про
карусель. Тринадцать из них — копии внутри форка `kinetic`, и это не дубли по
недосмотру: гарантия на одной копии ничего не говорит о другой.
