# 05-flows — сквозные сценарии

От события до кадра: клик, свайп, автоплей, поворот экрана, смена данных,
дальний переход с телепортом. Каждый — цепочка узлов с якорями, чтобы можно
было пройти путь целиком, не собирая его заново по файлам.

**Пишется последним, после проходов по слоям**: цепочку не составить, пока не
разобраны узлы, через которые она идёт. Сейчас файл пуст намеренно — это не
пропуск, а порядок работы.
