# `environment` — сигналы окружения пользователя

Что сообщают настройки и предпочтения пользователя. Сгруппировано по смыслу,
не по механизму.

| Папка | Содержимое |
| --- | --- |
| `library/` | Одиночные хуки: `useIsReducedMotion` (медиазапрос), `useIsTouchDevice` (детект указателя), `useDataSaver` (Network Information API). |
| `useUserEnvironment/` | Фасад: три сигнала одним мемоизированным объектом, читается один раз на границе приложения. |

Стора (`../shared/useMediaQuery`) касается только `useIsReducedMotion`;
остальные два держат свои маленькие источники.
