# `useUserEnvironment` — фасад окружения

Один хук возвращает единый мемоизированный объект сигналов окружения —
читается один раз на границе приложения и прокидывается куда нужно (карусель
принимает его пропом `userEnvironment` и сама окружение не определяет).

```ts
const env = useUserEnvironment();
// env.reducedMotion, env.touch, env.dataSaver  (стабильная идентичность объекта)
```

**Устройство.** `internal/` держит СВОИ копии трёх хуков-сигналов, поэтому
папка уносится целиком. Единственное общее — стор `../../shared/useMediaQuery`
(на нём стоит reduced-motion), его держим одним.
