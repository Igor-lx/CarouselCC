# `clientState` — что клиент реактивно сообщает о себе

Хуки, читающие живое состояние клиента пользователя — вьюпорт и его
предпочтения — и перерисовывающие компонент при изменении. Два домена плюс
общий стор:

| Папка | Назначение |
| --- | --- |
| `shared/` | **Стор.** `useMediaQuery` — один слушатель `matchMedia` на запрос, общий для всех здесь. Ровно одна копия на проект. |
| `media/` | Условия вьюпорта: тиры ширины, ориентация, медиазапросы. `library/` из отдельных хуков + фасад `useMedia/`. |
| `environment/` | Сигналы пользователя: reduced-motion, touch, data-saver. `library/` из отдельных хуков + фасад `useUserEnvironment/`. |

**Принцип.** Каждая заготовка держит свои копии используемых хуков, поэтому
любую папку можно унести отдельно. Единственное исключение — стор в
`shared/`: вторая копия расщепила бы реестр слушателей, поэтому он один и
лежит на виду.
