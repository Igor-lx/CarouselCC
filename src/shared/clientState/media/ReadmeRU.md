# `media` — реактивные CSS-медиаусловия

Всё про «выполняется ли сейчас медиаусловие» — тиры ширины, ориентация,
произвольные запросы. Два способа взять:

| Папка | Когда брать |
| --- | --- |
| `library/` | Нужно ОДНО: брейкпоинт, ориентация или один медиазапрос. Берёшь этот хук. |
| `useMedia/` | Нужен целый НАБОР сразу (тиры + ориентация + флаги) за один вызов и один сигнал изменения. |

Оба стоят на `../shared/useMediaQuery`. Фасад держит свои копии хуков
библиотеки (чтобы уноситься отдельно), но в проекте стор всё равно один.
