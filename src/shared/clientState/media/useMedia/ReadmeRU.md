# `useMedia` — фасад медиа

Один вызов резолвит целый набор осей медиа сразу.

```ts
const m = useMedia({ breakpoints: { desktop: 1024, mobile: 0 }, flags: { tall: "(orientation: portrait)" } });
// m.breakpoint  -> "desktop" | "mobile"
// m.orientation -> "portrait" | "landscape"
// m.flags.tall  -> boolean
// m.matches(q)  -> проверка произвольного запроса
// m.signature   -> меняется, только если изменился любой отслеживаемый вердикт (стабильная зависимость для эффектов)
```

**Устройство.** `internal/` держит СВОИ копии используемых хуков (резолвер
брейкпоинтов, запросы ориентации) плюс склейку; `useMedia.ts` — единственный
фасадный хук; `index.ts` — публичная поверхность. Копируя эту папку, ничего не
забываешь — кроме стора: он импортится из `../../shared/useMediaQuery` и
остаётся один на проект (этот файл берём с собой).
