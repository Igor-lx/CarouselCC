# `shared` — единственный стор

`useMediaQuery(query)` → живой `boolean`. Один реактивный `matchMedia`-стор:
на каждый уникальный запрос — один слушатель браузера, общий для всех
потребителей; корректное чтение на первом рендере и SSR-безопасный фолбэк.

**Почему лежит здесь и один.** Любая другая заготовка дублирует свои хуки,
чтобы переноситься отдельно. Стор так нельзя: вторая копия держит свой реестр
слушателей, и один запрос слушался бы дважды — гарантия «один слушатель на
запрос» действовала бы лишь в пределах копии. В проекте держим ровно **один**
`useMediaQuery.ts`; эта отдельная папка — напоминание взять его с собой и не
клонировать. Проверяет `tests/singleStore.test.ts`.

```ts
const isWide = useMediaQuery("(min-width: 1024px)");
```
