# `slots` — резолвер children в слоты

`resolveSlots(children, slotNames)` — читает React-`children` и возвращает
запись по известным именам слотов. Ребёнок попадает в слот, если его
компонент несёт совпадающий тег `type.slot`; побеждает последний, неизвестные
слоты отбрасываются (в dev — с предупреждением), отсутствующие возвращаются
как `null`.

Позволяет компоненту принимать составные части свободно (любой порядок, любое
подмножество) и читать их по имени.

```ts
const { header, footer } = resolveSlots(children, ["header", "footer"] as const);
```
