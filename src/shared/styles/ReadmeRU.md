# `styles` — слияние карт стилей

`mergeStyleMaps(...maps)` — объединяет несколько карт CSS-модулей,
конкатенируя строки классов по каждому ключу. Позволяет наложить переданные
вызывающим переопределения классов поверх собственной карты компонента, не
теряя оригиналы. Карты `null`/`undefined` и пустые значения пропускаются.

```ts
const cls = mergeStyleMaps(ownStyles, props.classNames);
// cls.track === "own_track abc123 userTrack"
```
