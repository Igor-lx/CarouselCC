# `kinetic` — готовое перетаскиваемое значение

Один хук, одно значение, один элемент: палец тащит его, отпускание катит по
инерции (или защёлкивает — твоя политика), кнопки «улетают» им, и каждый
проезд идёт WAAPI-анимацией на композиторе с JS-фолбэком. Самый готовый к
внедрению член коллекции.

## Какую заготовку брать?

| Задача | Заготовка |
| --- | --- |
| значение следует за пальцем + катится по кривым, простая докатка | **эта** |
| только движение — автоплей, прогресс, метры; без пальца | `../motion` |
| полный контроль — машина состояний уровня карусели, свои единицы | `../gesture` + `../motion` |

## Самодостаточен ПО ДУБЛИРОВАНИЮ

Импортирует **только React и себя** (стережёт `tests/portability.test.ts`) —
копируешь одну папку в любой React-проект, и работает. Несёт свои **форки**
движков жеста и движения (`./internal/gesture`, `./internal/motion`),
намеренно дублированные, а не импортированные. Форки могут расходиться с
оригиналами — по дизайну.

## Быстрый старт — всё приложение

```tsx
const kinetic = useKineticValue({ keyframe: (x) => ({ transform: `translateX(${x}px)` }) });
return (
  <div {...kinetic.hostProps}>
    <div ref={kinetic.ref} className="circle" />
    <button onClick={() => kinetic.flyTo(kinetic.value() + 200)}>→</button>
  </div>
);
```

Перетаскивание с инерционной докаткой, перехват на лету, проезды на
композиторе и JS-фолбэк — всё включено по умолчанию. Всё крутится через
`config` (`KINETIC_DEFAULTS`); политика докатки подключается одной функцией:

```tsx
useKineticValue({
  keyframe: (x) => ({ transform: `translateX(${x}px)` }),
  resolveTarget: ({ from }) => Math.round(from / 200) * 200, // сетка-защёлка
  onSettle: (x) => console.log("осел на", x),
});
```

## Границы (намеренно)

- **Одно значение, один движущийся элемент**, и значение **1:1 с пальцем**
  (пиксели). Размножение на много элементов или перевод пикселей в другие
  единицы — это «полный контроль», бери отдельные движки.
- Инерция встроена и невидима: встроенный форк жеста измеряет кинетику
  отпускания, а хук превращает её в проезд.
