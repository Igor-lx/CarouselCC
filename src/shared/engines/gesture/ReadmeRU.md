# `gesture` — превратить палец в намерение

Самодостаточный, независимый от компонента движок тач-свайпа. Один хук
встраивает продакшн-обработку горизонтального свайпа в любой компонент:
разложи `hostProps` на элемент, реагируй на колбэки — готово. Вся поверхность
экспортируется из `index.ts`.

## Устройство

| Папка | Роль |
| --- | --- |
| `swipe/` | Регистрация жеста: хук, host-пропсы, распознавание (`internals/` — приватное). |
| `inertia/` | Кинетический СМЫСЛ отпускания: `resolveReleaseKinetics` (суждение о флике + пуск-непрерывность) и `projectMomentum` (докатка по умолчанию); низкоуровневые `resolveInertialRelease`/`resolveReleaseLaunch` тоже экспортируются. |
| `tests/` | Свой сьют, включая `portability.test.ts`. |

Самодостаточен: импортирует только React и себя (стережёт
`tests/portability.test.ts`).

## Принцип

- **Только тач-указатели** (мышь/перо игнорируются — это клики и скролл).
- **Только горизонталь** — нажатие, ушедшее в вертикаль, отдаётся нативному
  скроллу; горизонтальное захватывается до отпускания.
- **Host не является поверхностью автоматически.** Передай `surfaceRef`, чтобы
  объявить перетаскиваемое поддерево; нажатия вне него (хром, лежащий поверх
  колоды) возвращаются браузеру — ни владения, ни тормоза, ни драга, и клик по
  ним не подавляется. Не передан — поверхностью считается весь host. Для
  точечного исключения ВНУТРИ поверхности пометь элемент
  `data-drag-ignore="true"` (`DRAG_IGNORE_ATTRIBUTE`).
- **Движок ВЛАДЕЕТ host-элементом** — `ref` в `hostProps` несёт слушатели,
  нужные стили и нативные подавители одним пакетом; проводки, которую можно
  сделать неверно, не остаётся.
- **Ноль ре-рендеров** — состояние в ref-ах, общение через колбэки.
- Физика считается по `event.timeStamp`, не по времени обработчика, поэтому
  скорости честны при загруженном main-thread.

## Быстрый старт

```tsx
const { hostProps } = usePointerSwipe({
  onDragMove: ({ uiOffset }) => (el.style.transform = `translateX(${uiOffset}px)`),
  onRelease: ({ direction }) => settle(direction),
});
return <div {...hostProps}>…</div>;
```

Для значения 1:1 с пальцем передай вместо колбэка `value: { read, write }` —
движок якорится на `read()` и пишет `anchor + offset`. Конфиг не обязателен
(`POINTER_SWIPE_DEFAULTS`); частичный `config` мёржится по полям.

## Ключевые экспорты

| Экспорт | Что |
| --- | --- |
| `usePointerSwipe` | Хук движка — возвращает `{ hostProps }`. |
| `POINTER_SWIPE_DEFAULTS` | Встроенный тюнинг (частичный `config` переопределяет). |
| `resolveReleaseKinetics`, `projectMomentum` | Смысл отпускания одним вызовом + политика докатки. |
| `resolveInertialRelease`, `resolveReleaseLaunch`, `sameDirectionSpeed` | Низкоуровневые примитивы отпускания. |
| `DRAG_IGNORE_ATTRIBUTE` | Пометить элемент как «не поверхность»: ни владения, ни драга (клик работает). |

## Связка с `motion`

Жесты сами по себе дают смещения, скорости и решение о коммите — достаточно
для CSS-переходов. Для нативного проезда добавь `motion`: смысл отпускания
отсюда кормит профиль `motion`, который исполняет контроллер. Соединяются по
рецепту, не импортом. Для нуля швов — заготовка `kinetic`.
