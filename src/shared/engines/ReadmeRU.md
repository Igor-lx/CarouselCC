# `engines` — заготовки движения / жестов

Три самодостаточные заготовки: анимировать значение и превращать палец в
намерение. Каждая импортирует только React и себя (стережёт
`tests/portability.test.ts`) — копируешь одну папку и работаешь.

| Папка | Что делает |
| --- | --- |
| `motion/` | Красиво провести числовое значение: кривые разгон/круиз/торможение + RAF-рантайм. Без пальца. |
| `gesture/` | Превратить перетаскивание указателя в намерение: биндинг свайпа + физика инерционного отпускания. Без анимации. |
| `kinetic/` | Готовое слияние: одно перетаскиваемое и «улетающее» значение в ОДНОМ хуке. Самодостаточен ПО ДУБЛИРОВАНИЮ — его `internal/` форкает `motion` и `gesture`. |

**Правило.** Движки не импортируют друг друга. `kinetic` несёт свои форк-копии;
форки могут расходиться с оригиналами — по дизайну. Выбор по задаче: только
значение → `motion`; только палец → `gesture`; и то и другое просто →
`kinetic`; и то и другое со своей логикой (машина состояний уровня карусели) →
`motion` + `gesture` как примитивы.
