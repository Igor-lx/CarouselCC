# `hooks` — разные общие React-хелперы

Небольшой бакет для общих React-утилит, не относящихся ни к одному домену.

- `useIsomorphicLayoutEffect` — `useLayoutEffect` в браузере и `useEffect` на
  сервере (SSR-безопасно: убирает предупреждение о layout-эффекте при
  серверном рендере).

Чистые, без зависимостей. Сюда — только действительно сквозное.
