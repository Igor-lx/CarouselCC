# `focus` — хелпер восстановления фокуса

`manageFocusShift(container)` — если сфокусированный элемент оказался скрыт
внутри `inert`-поддерева (например, после оседания карусели активная полоса
сместилась), переносит фокус на фокусируемый элемент в активной зоне, а при
его отсутствии — на контейнер. Обобщён: опирается на маркер
`data-active-zone="true"` и предка `[inert]`, так что конвенцию может принять
любой хост.

Чистый DOM, без React и состояния.
